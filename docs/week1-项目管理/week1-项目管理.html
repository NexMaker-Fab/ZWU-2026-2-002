项目管理 —— 网站开发指南

Project Management - Website Development Guide

准备网站开发所需工具

1. Github：用于存放我们的网站项目

2. GitHub Desktop：用于克隆代码仓库、上传本地文件

3. AI 智能开发助手（通义灵码）：用于编写网站代码

操作步骤

第一步：在 GitHub 上创建一个新仓库来托管您的网站

登录 GitHub 后，点击右上角的 "+" 按钮，选择 "New repository"（新建仓库），如下图所示：

创建新仓库界面

第二步：命名您的存储库，选择它是公共的还是私有的。添加一个README文件来共享您的信息，然后单击"创建存储库"按钮。

在创建仓库页面中：

  • 1. Repository name（仓库名称）：输入您的仓库名称
  • 2. Choose visibility（选择可见性）：选择 Public（公开）或 Private（私有）
  • 3. Add README（添加 README）：开启此选项以自动生成 README 文件

完成设置后，点击绿色的 "Create repository"（创建存储库）按钮即可。
