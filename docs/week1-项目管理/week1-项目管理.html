项目管理 —— 网站开发指南

Project Management - Website Development Guide

准备网站开发所需工具

1. Github：用于存放我们的网站项目

2. GitHub Desktop：用于克隆代码仓库、上传本地文件

3. AI 智能开发助手（通义灵码）：用于编写网站代码

操作步骤

第一步：在 GitHub 上创建一个新仓库来托管您的网站

登录 GitHub 后，点击右上角的 "+" 按钮，选择 "New repository"（新建仓库），如下图所示：

创建新仓库界面

第二步：命名您的存储库，选择它是公共的还是私有的。添加一个README文件来共享您的信息，然后单击"创建存储库"按钮。

在创建仓库页面中：

  • 1. Repository name（仓库名称）：输入您的仓库名称
  • 2. Choose visibility（选择可见性）：选择 Public（公开）或 Private（私有）
  • 3. Add README（添加 README）：开启此选项以自动生成 README 文件

完成设置后，点击绿色的 "Create repository"（创建存储库）按钮即可。

配置仓库信息界面

第三步：将页面设置为空。点击存储库的设置，选择左侧的"Pages"。选择"main"和"/root"并保存。上面的链接允许您查看该页。

创建仓库后，需要进行以下设置以启用 GitHub Pages：

  • 1. 进入 Settings（设置）：点击仓库顶部导航栏中的 "Settings" 按钮
  • 2. 选择 Pages：在左侧菜单中找到并点击 "Pages" 选项
  • 3. 配置部署源：在 "Branch" 下拉菜单中选择 "main"，文件夹选择 "/ (root)"
  • 4. 保存设置：点击 "Save" 按钮保存配置

提示：保存后，页面顶部会显示您的网站访问链接，您可以通过该链接查看已发布的网页。

GitHub Pages 设置界面

第四步：等待GitHub检索并生成页面，待所有项目完成后，网站即可初步搭建完成。

完成上述设置后：

  • 1. GitHub 自动构建：GitHub 会自动检索您的仓库文件并生成静态页面
  • 2. 查看部署状态：在右侧 "Deployments" 区域可以看到部署进度和状态
  • 3. 访问网站：部署完成后，您可以通过之前保存的链接访问您的网站
  • 4. 上传项目文件：将本地开发的项目文件（HTML、CSS、JavaScript等）上传到仓库中

提示：如上图所示，点击 "Code" 标签可以查看仓库中的所有文件和文件夹结构。绿色对勾表示文件已成功提交。

仓库文件列表界面

总结：通过以上四个步骤，您已经成功完成了 GitHub 网站的初步搭建。接下来可以使用 GitHub Desktop 克隆仓库到本地，使用通义灵码等 AI 助手编写网站代码，然后将代码上传到 GitHub，您的网站就会自动更新并显示在 GitHub Pages 上。

使用 GitHub Desktop 克隆仓库

第五步：将代码仓库克隆至GitHub Desktop

打开 GitHub Desktop 后：

  • 1. 点击 "Add"（添加）按钮：在左上角找到并点击 "Add" 下拉菜单
  • 2. 选择 "Clone repository..."（克隆资源库）：从下拉菜单中选择此选项
  • 3. 选择仓库：在弹出的窗口中找到您需要克隆的仓库
  • 4. 点击 "Clone"（克隆）：确认路径后点击克隆按钮

提示：克隆完成后，仓库会出现在 GitHub Desktop 的左侧列表中，您就可以开始在本地编辑文件了。
