一、项目主题（Topic）

本项目为艺术疗愈手部精细动作康复训练装置设计，是一款融合光影艺术互动与手部机能康复的智能交互设备。项目打破传统机械式康复训练模式，以艺术疗愈理念为核心，面向脑卒中后手功能障碍老年患者、手部活动受限康复人群，以及需要锻炼手部精细动作的低龄儿童，通过可视化光影互动游戏，实现手部机能康复与情绪舒缓的双重疗愈效果。

二、解决用户问题（Solve which problem for customer）

  1. 传统康复训练枯燥乏味、依从性差：传统手部康复多为机械重复的屈伸、抓握训练，过程单调枯燥，老年康复者易产生抵触、倦怠心理，儿童容易注意力涣散，导致训练中断、康复效果不佳。
  2. 只练身体、不疗情绪：术后、脑卒中康复人群长期面临焦虑、低落情绪，普通康复设备仅锻炼肢体，忽略心理情绪疏导；儿童精细训练也缺乏趣味陪伴，训练体验冰冷生硬。
  3. 康复过程无互动、无反馈、无成长感：常规训练无法直观体现手部灵活度进步，用户难以获得成就感，无法持续激励自主训练；传统设备无法量化手部精细动作的恢复程度。
  4. 医用康复设备门槛高、不普惠：专业智能康复器械体积大、价格昂贵、场景受限，无法满足居家、日常、轻量化的长期康复与美育训练需求。

三、项目创新点（Innovation）

  1. 跨维度创新：艺术疗愈 + 机能康复双向融合
    区别于市面上纯功能性的康复器械，本项目将光影艺术交互、情绪疗愈、手部机能康复三者结合，不仅训练手指力度、灵活度、精细控制能力，还通过柔和光影互动舒缓情绪、缓解康复焦虑，实现“身体康复+心理疗愈”双重价值。
  2. 场景创新：适老化与适童化双适配
    装置同时适配中老年后手功能障碍康复与低龄儿童手部精细动作启蒙训练，一套设备覆盖“老年康复+儿童成长”双场景，适用人群更广、实用性更强。
  3. 交互创新：光影趣味互动替代机械训练
    摒弃枯燥的重复动作训练，以光影小游戏、视觉反馈互动为载体，让用户在趣味体验中无意识完成手指屈伸、按压、精细操控训练，大幅提升训练主动性与坚持度。
  4. 效果可视化创新
    游戏开始（OLED 显示开始提示）→ 用户按照提示按压三个传感器（灯带不同结果反馈、蜂鸣器即时反馈正误、OLED 更新得分）→ 小屋灯带随得分变化呈现动态光效 → 游戏结束（OLED 显示总分与鼓励语）→ 旋转定位器调节难度进入下一轮。通过 “触觉 + 视觉 + 听觉” 多感官联动，将枯燥的康复训练转化为有目标、有反馈、有成就感的互动游戏，让用户在光影与得分中持续获得坚持的动力。

四、市场分析（Market）

  1. 同类产品现状
    目前市面手部康复产品分为两类：一类是医院专业康复机器人、功能康复仪，侧重肢体训练，无艺术交互、无情绪疗愈功能，设备昂贵、场景受限；另一类是儿童精细训练玩具，仅有娱乐功能，无专业康复数据检测，无法用于康复评定。目前市场暂无艺术疗愈+光影互动+双人群适配的一体化康复装置。
  2. 价格对比
    医用智能康复设备售价数千至上万元，儿童益智训练器材功能单一、无智能检测。本装置以低成本嵌入式方案实现专业康复测评+艺术光影疗愈功能，性价比极高，适合家庭、社区、校园普惠使用。
  3. 市场渠道
    可面向社区康养中心、老年日间照料中心、特殊康复机构、幼儿园美育课堂、普通家庭用户推广，依托社区公益试点、校园科创展示、线上康养科普渠道落地，推广门槛低、应用场景丰富。

五、核心技术与潜在技术问题（Key tech analyse and Potential tech problem）

1. 核心技术

  1. 总传感器按压模块：控制游戏的开始与停止。
  2. 三传感器按压模块：三传感器按压模块分别对应三种不同颜色（白绿蓝），用户需按灯带提示颜色分别按动三个传感器，每个传感器感应不同力度阈值，训练手指力量控制与精细动作协调能力。
  3. OLED 屏幕反馈：实时显示当前正确和错误、游戏开始/结束提示及操作引导，让用户清晰了解每一次互动的结果与整体进度。
  4. 旋转定位器调节：支持三级游戏难度调节（简易/中等/进阶），不同难度对应不同的力度要求和按压节奏，适配不同康复阶段的用户需求。
  5. 蜂鸣器提示：按压正确时播放柔和短促的"滴"音效，错误时发出温和提示音，与灯带颜色形成视听双重反馈。
  6. 3D 打印互动小屋反馈：小屋采用 3D 打印，内部装有 WS2812B 全彩灯带。互动正确时呈现五颜六色流动光效，错误时转为红色警示光效，通过即时灯光反馈带来情绪安抚与视觉享受。

2. 潜在技术问题

  1. 手指精细动作幅度微小，极易受外界轻微震动干扰，容易造成数据采集轻微偏移；
  2. 老年用户与儿童手部发力方式、动作幅度差异大，统一交互算法难以完全适配两类人群；
  3. 光影交互灵敏度需持续调试，灵敏度过高易误触发，过低则影响艺术互动体验与训练效果。

六、材料与制作工艺（Material and how to make it）

1. 核心硬件与结构材料选型

  • Arduino UNO：整套设备的控制核心，统筹所有器件信号。
  • WS2812B 灯带：装在 3D 打印小屋内，用不同灯光反馈按压正误。
  • 旋转电位器：旋钮调节简易、中等、进阶三档训练难度。
  • 蜂鸣器：发出提示音，实现听觉反馈。
  • 1.54 寸 OLED 屏：实时显示正确和错误、操作提示与训练结果。
  • 杜邦线：连接所有电子元件，传输电路信号。
  • 薄膜压力传感器：采集手指按压力度，作为游戏操作输入。
  • 3D 打印机：打印互动小屋外壳，容纳灯带完成视觉交互。

装置主体是一座 3D 打印成型的双层卡通咖啡馆小屋，整体造型童趣柔和，摒弃了传统康复器械冰冷刻板的外观。小屋内部中空，内置 WS2812B 全彩灯带，是整套设备的视觉反馈核心；小屋外部搭配配套按压传感配件，兼具桌面摆件的装饰性与康复训练交互功能，柔和治愈的外观能降低老人、儿童对训练设备的抵触感。。

2. 制作流程（聚焦3D打印结构制作）

第一步：结合人体手部工学尺寸，适配老人康复、儿童训练双使用场景，通过Fusion 360完成个性化穿戴支架、传感器固定卡扣、光影外壳的三维建模，优化曲面贴合结构与光影通透结构；

第二步：采用PLA哑光白耗材进行3D打印制作，打印完成后对结构边缘打磨抛光，去除毛刺，保障穿戴舒适度与设备整体艺术质感；

第三步：完成ESP32主控、各类传感器、光影灯组的电路焊接、线路规整与模块组装，搭配EVA海绵、加宽魔术贴优化穿戴贴合度；

第四步：基于Arduino IDE编写手部数据采集、光影艺术交互、趣味康复游戏、训练评分测评程序，完成程序烧录与基础调试；

第五步：整机联调校准传感精度、光影反馈灵敏度与游戏交互逻辑，优化结构适配性，最终实现艺术疗愈、手部精细康复训练、量化测评一体化功能，完成样机制作。

七、SDGs可持续发展解决方向（Solve some problem in SDG）

本项目主要对应联合国可持续发展目标 SDG 3：良好健康与福祉 与 SDG 4：优质教育。

  1. 助力普惠康养：以低成本艺术疗愈康复装置，为中老年功能障碍人群提供居家康复途径，缓解医疗资源压力，提升康复人群身心健康与生活品质。
  2. 赋能儿童美育与成长：通过艺术互动训练，在锻炼儿童手部精细动作的同时，培养艺术感知力，实现健康训练与美育启蒙结合。
  3. 推进身心协同健康：打破单一身体康复模式，关注用户心理健康与情绪疗愈，推动全民身心健康、普惠康养与素质教育的可持续发展。
