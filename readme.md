# 下肢康复训练智能提示器

## 项目简介

本项目旨在打造一款面向家庭与基层康复场景的下肢康复训练智能提示器。系统通过传感器实时采集下肢动作、提供语音/视觉提示、并根据康复进度生成训练建议，帮助患者规范训练、提升康复效果。

## 痛点分析

- 专业康复训练缺乏指导，患者易出现动作不标准或训练过量。
- 高端康复设备成本高、体积大，难以普及到家庭和社区康复。
- 传统训练单调，患者坚持性差，康复进度难以稳定提升。

## 产品价值

- 智能提示：实时监测下肢动作姿态，并提示正确训练方式。
- 方案管理：支持个性化康复计划与阶段性目标设定。
- 数据反馈：记录训练数据，生成康复报告，辅助康复师评估。
- 适用场景：家庭康复、社区康复中心、术后康复随访。

## 案例分析

### 1. Open-Source Leg (OSL)（密歇根大学）

**共同点：**  
该平台同样关注下肢康复与动作分析，强调传感器与控制系统的统一设计。

**优势：**
- 标准化硬件接口，便于结合多种传感器和执行器；
- 社区支持良好，适合提取算法与步态分析经验；
- 适合科研验证和控制策略调优。

**劣势：**
- 更侧重实验室研究，不适合家用康复设备场景；
- 成本和部署复杂度较高；
- 需要较高的开发和维护门槛。

**启发：**  
可借鉴其动作监测与数据分析框架，将成熟算法迁移到轻量化家用设备上。
