## 案例分析

### 1. Open-Source Leg (OSL)（密歇根大学）

**共同点：**  
作为下肢康复与假肢研究的标准化平台，支持步态分析与控制算法研发。

**优势：**
- 提供统一的传感器 / 执行器接口，降低算法开发门槛；
- 全球 30+ 学术机构采用，社区成熟，论文与案例丰富；
- 支持生物力学建模与步态预测算法，科研价值高。

**劣势：**
- 定位差异：偏向实验室研究，非家用康复设备设计；
- 成本较高：定制化电机与传感器导致整体成本不低；
- 复杂度高：对开发者的机械 / 电子 / 算法能力要求高。

**对你的启发：**  
可作为算法验证平台，先在 OSL 上调试控制策略，再迁移到你的家用化设备中。

### 2. MIT协议（Massachusetts Institute of Technology License）

MIT协议是一种源自麻省理工学院的宽松型开源许可证，以简洁、自由度高著称。它允许任何人免费使用、复制、修改、合并、发布、分发、再授权甚至销售软件及其文档，唯一要求是在软件及相关文档中保留原作者的版权声明和许可声明。

**核心特点：**
- 极度宽松：几乎不对使用、分发、修改施加限制。
- 易于遵循：协议文本简短明了，非法律专业人士也能轻松理解。
- 广泛兼容：可与GPL、BSD等大多数开源协议共存。
- 商业友好：允许闭源商业化，无“传染性”条款。

**与其他协议对比：**
- GPL：要求衍生代码必须开源（传染性），MIT无此限制。
- Apache 2.0：包含专利授权条款，MIT更简洁。

**使用边界与注意事项：**
- 保留声明：无论修改或分发，必须保留原版权和许可文本。
- 免责条款：软件“按原样”提供，原作者不对缺陷或后果负责。
- 无专利保护：若涉及专利需额外声明。
- 不强制回馈：改进代码可不回馈社区，这既利于商业化，也可能减少社区贡献。

**典型应用场景：**
- 个人/小型项目：快速推广代码（如开源工具库、算法实现）。
- 企业级项目：在保持商业灵活性的同时扩大生态（如React、VS Code）。
- 教育科研：分享研究成果，促进协作。
